# Sticker Studio Pro

I want you to build a website that sells custom telegram sticker maker. I'd like it to the following features: a place where they can upload their files and get started. they can give the style of the sticker they want i.e. animated vector, 3d, realistic. Then an option where they can pay to get their stickers.

This project was built with [Lovable](https://lovable.dev).
